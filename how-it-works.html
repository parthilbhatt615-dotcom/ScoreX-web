Workflow

How ScoreX works

The current workflow follows the sequence documented in the master project file.

1

Create Match

Enter team names, overs, toss winner and decision.

2

Configure

Set players-per-team and special-delivery behavior.

3

Opening Players

Select striker, non-striker and opening bowler.

4

Live Scoring

Record one delivery at a time.

5

Innings Completion

Complete the first innings and initialize the chase.

6

Second Innings

Score the chase using the same rules.

7

Result

Calculate the final result after the required innings state is complete.

8

Scorecard / Graphs

Review batting, bowling, extras, wickets, overs and visual analytics.

9

PDF / History

Generate a formatted PDF and retain the match locally.

Example rules

Small examples matter.

The documentation explicitly calls out special deliveries where more than one state changes.

🏃

1 + W

One completed run is retained with the run-out wicket.

🏃

2 + W

Two completed runs are retained with the wicket.

🚫

No Ball + 4

The no-ball extra and batsman runs are separate components of the delivery.
