ScoreX Website

Open index.html.

APK: place the final Android APK at downloads/ScoreX.apk. The Download App button points to it automatically.

Project documentation is presented directly on features.html. There is no separate Docs page.

Feedback: the contact form prepares a mail to scorex.feedback@gmail.com using the visitor's default email application.

GitHub: the website currently links to GitHub at https://github.com/. Replace that URL with the ScoreX repository URL when available.

Contact form recipient: scorex.feedback@gmail.com. The static website opens the visitor's configured email application with the form details pre-filled.
